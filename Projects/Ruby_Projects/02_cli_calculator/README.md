# CLI Calculator

**Level:** Beginner

## Goal
Create a command-line calculator supporting addition, subtraction, multiplication and division.

## Concepts
- Methods
- Parameters and return values
- `case` statements
- Numeric conversion
- Error handling

## Run
```bash
ruby main.rb
```

## Your tasks
1. Implement `add`, `subtract`, `multiply`, and `divide`.
2. Ask the user for two numbers and an operation.
3. Handle invalid operations.
4. Prevent division by zero.
5. Add tests after the basic version works.
