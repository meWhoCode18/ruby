# Number Guessing Game

**Level:** Beginner

## Goal
Build a terminal game where the computer chooses a secret number and the player guesses it.

## Concepts
- Variables and constants
- `gets` / `chomp` / `to_i`
- `if` / `elsif` / `else`
- Loops
- `rand`
- Input validation

## Run
```bash
ruby main.rb
```

## Your tasks
1. Generate a random number from 1 to 100.
2. Ask the player for guesses.
3. Say whether each guess is too high or too low.
4. Count attempts.
5. End when the player guesses correctly.
