# Contact Book

**Level:** Beginner → Intermediate

## Goal
Store, list, search, add, and delete contacts from the terminal.

## Concepts
- Arrays and hashes
- Methods
- Loops and menus
- File I/O
- JSON persistence

## Run
```bash
ruby main.rb
```

## Your tasks
1. Represent each contact as a hash with name and phone.
2. Add and list contacts.
3. Search by name.
4. Delete a contact.
5. Save contacts to `contacts.json` and load them on startup.
