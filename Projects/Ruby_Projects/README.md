# Ruby Projects

A hands-on Ruby project path from beginner to advanced. Each project has its own folder and README.

## Recommended order
1. Number Guessing Game
2. CLI Calculator
3. Contact Book
4. Expense Tracker
5. Quiz Application
6. File Organizer
7. API Client
8. Ruby Testing Lab

## Working rules
- Build one project at a time.
- Read its README before coding.
- Try independently before asking for a solution.
- Keep code readable and commit each completed milestone.
- Never test file-moving scripts on important files.
- Do not commit secrets, API keys, or personal data.

These are learning scaffolds, not completed solutions. The goal is to implement and understand each project yourself.
